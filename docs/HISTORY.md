# Historia de Patito Online Judge

[Volver al README principal](../README.md)

Patito Online Judge comenzó en 2012 con las primeras pruebas de jueces en línea para enseñanza y entrenamiento de programación competitiva en la Universidad Mayor de San Andrés (UMSA).

En esa etapa se probaron varias alternativas para recibir código y evaluarlo de forma automática. Finalmente se eligió HUSTOJ como base. A partir de ahí se trabajó en la instalación, traducción, configuración y adaptación del sistema para cursos y competencias de la universidad.

Las primeras instalaciones funcionaron en servidores de la UMSA. Con ellas se organizaron concursos, entrenamientos y actividades de distintas materias de programación y algoritmos.

Con los años se cambiaron la interfaz, el sistema de evaluación, la administración de concursos, la gestión de problemas y la infraestructura. Mucho de ese trabajo ocurrió antes del repositorio Git actual, así que el historial de commits muestra solamente una parte del desarrollo del proyecto.

## Línea de tiempo

- **2012:** primeras pruebas documentadas con HUSTOJ. Se revisaron lenguajes, compilación del judge, configuración y adaptaciones iniciales.
  - [Pruebas de código y configuración en HUSTOJ — registro 1](https://ideone.com/yhu8Yc)
  - [Pruebas de código y configuración en HUSTOJ — registro 2](https://ideone.com/13cHHw)
- **2013:** continuaron las pruebas técnicas y la preparación de infraestructura para entrenamiento y uso académico.
- **2014:** se desplegaron las primeras instancias usadas por estudiantes y docentes de la UMSA. También se tradujeron y adaptaron partes de la plataforma.
- **2014–2017:** Patito se consolidó como apoyo para cursos, entrenamientos y competencias de programación.
- **2018:** se probaron nuevas interfaces, componentes para concursos y rankings, APIs y soporte para MathJax.
- **2019–2024:** se estabilizó la plataforma, se amplió la gestión de problemas y se agregó soporte para nuevos entornos de ejecución.
- **2024–presente:** comenzó la modernización por servicios, el nuevo panel administrativo y Patito IDE con Monaco Editor y soporte LSP.
